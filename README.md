## Bin2Dec

Conversor de binário para decimal utilizando Python, biblioteca PyQt usando o módulo QtWidgets.

Para utilizar é apenas necessário ter Python instalado em sua máquina e instalar o PyQt no repositório utilizando o comando:

`pip install PyQt6`   

e baixar o arquivo principal Bin2Dec.py.

obs: deixei disponivel uma versão CLi sem interface gráfica apenas terminal com o nome Bin2DecCLi.py.
